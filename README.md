# four-cylinder-engine
Task 3 – Four Cylinder Engine 3D Modeling

A simplified four-cylinder engine assembly was designed and modeled using SolidWorks.

The project workflow included:

- Designing individual engine parts such as:
  - Pistons
  - piston_ring
  - Connecting rods
  - Crankshaft
- Creating assembly constraints and positioning components correctly with the right mates 
- Applying materials and appearances to the components
- Creating realistic rendering and presentation views
- Finalizing the complete engine assembly model

This project demonstrates 3D modeling, assembly design, rendering, and mechanical engineering visualization skills.

Software Used

- SolidWorks
